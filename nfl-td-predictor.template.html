Bet log & CLV

📓 Log every bet — the sim's TD props or your own player props (yards, receptions, anything) — and track CLV (did you beat the closing line?) and ROI. This is the only honest read on whether the sim actually makes money — aim for 50–100 bets before trusting it.
☁ One bet log on every PC. Each browser keeps its own copy, so two PCs drift apart. Sync keeps your bet log, slip and bankroll in a private gist on your GitHub account, and every PC you connect merges into it. One-time setup on each PC / browser:
  1. Make a token that can only touch gists: GitHub → new token (gist scope pre-ticked) → pick an expiration → Generate token → copy it.
  2. Paste it below and hit Connect. On your other PC, do the same (a second token is fine, or reuse this one).
The token is saved in this browser only — never in the site's code — and can't do anything but read/write your gists. Syncs a few seconds after every change, whenever you come back to the tab, and every 90 s. Deleting a bet (or Clear log) deletes it on every synced PC.
